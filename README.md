# Next LvL Gaming Website

A dark-themed gaming brand website for Next LvL Gaming, featuring a storefront, product pages, contact and enquiry flows, founder story, and account/cart interactions.

## Overview

This project is a static marketing and e-commerce website built with HTML, CSS, and JavaScript. It includes:

- Home page with gaming branding and hero sections
- About page with founder narrative and brand story
- Product showcase and merchandising layout
- Contact page with interactive details and support information
- Enquiry and signup flows
- Cart/account/profile interactions using browser localStorage

## Project structure

- `Index.HTML` — home page
- `About.html` — brand story and founder section
- `Products.html` — product listings and add-to-cart UI
- `contact.html` — contact page and support details
- `enquiry.html` — enquiry form page
- `styles.css` — site-wide styling, animations, and theme
- `Images/` — branding, imagery, and product assets

## Run locally

Because this is a static website, you can either:

1. Open any HTML file directly in a browser, or
2. Serve the project locally:

```bash
cd "c:\Users\Student\Documents\NextLvL Project\Gaming Website"
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000/Index.HTML
```
